# Medal demo texture sources

The texture files in this directory were copied from
[`simeydotme/pokemon-cards-css`](https://github.com/simeydotme/pokemon-cards-css)
at commit `acb1197633e749a1fba4412231db2f6581586d00` for the local medal demo.

- `illusion-mask.png`: alpha mask for the foil layer.
- `illusion.png`: interference texture for the foil layer.
- `glitter.png`: grain texture for the foil highlight.

The source repository is licensed under GPL-3.0. Its license text is preserved
as `LICENSE.pokemon-cards-css.txt`. No Pokemon card artwork is included.
