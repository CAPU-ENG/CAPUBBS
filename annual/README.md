# 电子年刊

总入口为 `/annual/`（访问 `/annual` 会跳转到带斜杠的地址）。入口自动读取本目录下四位年份文件夹，只展示包含 `index.html` 的年份，按年份倒序排列。没有年刊时显示“暂无年刊”。入口不依赖数据库或论坛登录，不需要构建前端。目录使用纸色、细纹理、书脊印记、双线分隔与册序编号点缀。

## 内容独立约定

`annual` 负责发现年刊及进入前的下载准备。目录链接先到 `/annual/read.php?year=2026` 这样的加载页，完整下载后再打开该文件夹的原始 HTML。目录和加载页不会改写正文，也不会给年刊注入 CSS、JavaScript、导航、页眉页脚或 iframe 外壳。

每份年刊自行决定 HTML 结构、布局、配色、字体、交互、资源组织和是否提供返回目录的链接；无需遵循 demo 的类名、版式或脚本约定，也不依赖论坛登录、组件、构建系统或父目录资源。可以直接放入另外制作的完整静态网站，包括自己的子页面。以相对路径引用文件夹内的资源后，整个年份文件夹可独立作为静态网站根目录使用。

目录自动收录只约定两件事：外层文件夹为四位年份，入口文件为 `index.html`。下面的 CSS、JS 文件名和 `assets/` 组织仅是示例，目录程序不检查它们。

目录列表显示年份及可选的年刊标题，不重复显示“年刊”。在目录侧的 `annual/titles.json` 中按年份填写标题，例如 `"2026": "山野之间"`；未填写、留空或配置无法读取时只显示年份。标题以纯文本显示，不读取或约束年刊正文的 HTML、页面标题和布局，也不影响年份的自动收录。

## 加载过程

先呈现加载页，再通过 `read.php?year=年份&manifest=1` 获取该年份目录中的文件清单。对于配置了远程资源清单的年份，加载页还会读取 `annual/remote-manifests/年份.json`，把对象存储中的图片、字体等资源合并到下载队列。清单仅列出文件地址与大小，不计算内容哈希或生成版本快照。隐藏文件、符号链接、服务器脚本及文档/备份等非发布文件不参与下载；年刊目录应只放需要公开的静态站点成品，不要混入开发依赖。

加载页使用普通 `fetch` 同时下载至多四个文件，按实际读取字节显示进度。只有所有响应内容读取完成、字节数与清单一致后才显示 100% 并进入正文；HTML 和脚本在下载阶段不会执行。下载过程中只统计数据流，不将整刊留在 JavaScript 内存中。不支持流式读取的浏览器按单个文件读取完成后更新进度。失败或超时时停留在加载页，可重新加载；流式下载以连续 60 秒无数据为超时，非流式读取以单次读取 60 秒为限。离开加载页会取消本页未完成的请求。

本地页面文件使用 `cache: 'no-cache'`，远程 OSS 资源使用浏览器默认缓存策略；首次下载后，后续是否复用资源由 OSS 返回的 HTTP 缓存规则决定。全部下载后直接跳转原始年刊 URL，后续资源请求与音视频 Range 请求由浏览器和服务器正常处理。不使用 Service Worker、Cache Storage、内容版本绑定或离线快照，普通 HTTP 地址也能预加载。

没有配置远程清单时，文件清单只覆盖该年份目录里的本地静态资源。外部 CDN、其他目录的文件和脚本动态请求的接口不属于整刊下载；要让整份年刊在打开前准备齐全，应将资源放入年份文件夹，或为远程资源维护对应的 `remote-manifests/年份.json`。

直接访问 `/annual/2026/` 或将文件夹单独部署时，仍然按普通独立网页运行，不经过加载页。档案室或外部链接若需要相同加载流程，应使用 `/annual/read.php?year=2026`。加载页完成后会替换当前历史记录，返回上一页时直接回到原入口。

每年使用独立目录，例如以下结构对应 `/annual/2026/`：

```text
annual/
├── index.php
├── style.css
└── 2026/
    ├── index.html
    ├── style.css
    ├── script.js
    └── assets/
        ├── cover.webp
        └── …
```

目前包含 `2026/`（通栏山野封面）和 `2025/`（海岸杂志分栏）两份不同版式的独立 demo，页面标有 DEMO，文字为示例内容。两份 demo 各自包含 `index.html`、`style.css`、`script.js` 和 `assets/cover.svg`，支持展开、收起札记，没有父目录或相邻年份依赖。正式年刊可整体替换对应年份内的文件，不需要保留任何 demo 代码。

`2023/` 是《行者 2023·总第二十五期》的网页版，按原刊配色重新设计：首页沿用封面的天空蓝与题字，依次为封面、2023 暑期路线图、完整目录、《跋涉梦想》、封底“行者是谁”与编委信息；目录按“暑期特写（实践团、骑行团、飞行团）／行者足音／此刻回首／附”分栏，分别使用原刊的青、橙、暮色配色。目前《CAPU 行者骑迹 28 年》《2023 车协年大事记》《步步且前前》、“暑期特写”实践团、骑行团、飞行团、“行者足音”五篇文章、“此刻回首”五篇文章及“附”两篇内容共三十九篇有网页正文，其余目录项只列标题、作者和原刊页码。《骑迹》把原刊跨页地图做成可交互的中国地图：列出 1996—2023 年全部 34 条暑期路线，节点按原刊，节点之间的道路走向取自 OpenStreetMap 路网（经 OSRM 规划，吉隆—加德满都一段因路网绕行改为手绘），省界与南海诸岛插图来自 DataV；点选年份后地图缩放到该路线并逐段绘出、标注地名，再次点选或按 Esc 回到全图，原刊“说明”附在页末。实践团《人物志》收录 13 位团员的原刊照片、手写体称呼与全文介绍，顶部有头像索引可跳转到各人。《大事记》按原刊做成横向时间轴：彩带路面沿用原刊五段配色，事件卡片上下交错并以虚线连到路面，年份以路碑标出；可横向滚动、鼠标拖动（带惯性）、在时间轴上用竖向滚轮横移或点左右箭头，触屏使用原生横滑。目录和文章页中的数字均为印刷页码。路线图为内嵌 SVG：西安—兰州—青海湖—嘉峪关沿国道的近似真实路线取自 OpenStreetMap 路网（经 OSRM 规划），省界来自 DataV 行政区划数据，青海湖轮廓来自 OpenStreetMap，页面内标注数据来源。`script.js` 负责首页路线图进入视口时的逐段绘制动画、《骑迹》地图的选择、缩放与地名标注，以及《大事记》时间轴的拖动、滚轮横移与箭头按钮、年刊内链的同文档路由与转场控制；无脚本时两张地图都直接显示全部路线，开启“减少动态效果”时不播放动画。年刊内链由 Fetch + History API 在当前文档中切换正文，支持 View Transition 的浏览器同时过渡旧页和新页，其他浏览器使用横条转场降级；首次打开首页不播放。暑期特写图片底部叠加由下向上的线性遮罩。阅读进度条使用 CSS 滚动时间线，不支持的浏览器不显示。图片按原刊 PDF 内嵌图像裁切并以 WebP 保存：文章内图片控制在 500 KB 以内，首页大图控制在 1 MB 以内，保留清晰度的同时降低首次下载体积。中文正文使用按年刊字符集子集化的思源宋体、思源黑体 WOFF2，当前资源目录已迁移至 `https://capu-annuals.oss-cn-beijing.aliyuncs.com/2023/assets/`，由 `annual/remote-manifests/2023.json` 纳入首次加载清单。题字“行者”取自封面原图并去除底色。原始 PDF 不随网页放入年份目录。直接访问 `/annual/2023/` 会绕过加载页，或从总入口经 `/annual/read.php?year=2023` 进入完整下载流程。

新增年刊时，将完成的整套网页放入对应年份目录，保留 HTML、CSS、JS 和资源的相对位置。CSS、JS 文件名可自定，HTML 入口统一为 `index.html`。只有已经放入 `index.html` 的年份才会出现在总入口。

年刊内使用相对路径引用自己的资源：

```html
<link rel="stylesheet" href="./style.css">
<script src="./script.js" defer></script>
<img src="./assets/cover.webp" alt="年刊封面">
```

每份年刊是独立的完整网页，直接访问，不嵌入论坛。若年刊作者希望提供返回总入口的导航，可自行添加 `<a href="../">历年年刊</a>`；这是可选的站点内链接，单独部署到其他位置时需自行调整。需要长期保存的图片、字体等资源也应随年刊放入自己的目录。引用目录地址时保留末尾 `/`，避免相对资源路径指向上一层。

在仓库根目录启动本地服务：

```bash
php -c php.ini -S localhost:8080 router.php
```

通过 `http://localhost:8080/annual/` 访问。Vite 开发服务也会把 `/annual` 请求转发给 `CAPUBBS_PHP_ORIGIN` 指定的本地 PHP 服务。

也可以完全绕开目录页，在仓库根目录运行 `php -S localhost:8084 -t annual/2026`，直接访问 `http://localhost:8084/` 查看单份年刊。

## 档案室收录

档案室现有“添加帖子”支持站内路径及 HTTP(S) 地址。需要先加载整刊时，填写 `/annual/read.php?year=2026` 或 `https://chexie.net/annual/read.php?year=2026`；也可继续使用直接正文地址 `/annual/2026/`。手动填写“帖子名称”，例如“2026 年刊”；自动提取名称只支持论坛帖子，不能识别年刊标题。需要具备档案室管理权限。

档案室保存的是地址及名称，打开条目会直接访问年刊；它不会复制网页及其资源，也不会将该目录变为私有。为保持链接有效，应保留年份目录及文件路径。需要文件备份时，可另外将整份年刊打包后上传到档案室。

## 服务器路径

部署时将 `annual/` 中的目录页、加载页、`loader.js`、样式、标题配置和各年份目录保留原结构放到站点根目录下，并保留历年内容。入口及加载清单由 PHP 执行，年刊 HTML/CSS/JS/assets 作为静态文件提供。站点需配置 `index index.php index.html`，按真实文件处理 `/annual/`，不存在的页面和资源返回 404。现有部署文档中的 Nginx 规则已满足这一结构；不要将 `/annual/` 重写到论坛的单页入口。加载页和文件清单不能经过整页缓存。
