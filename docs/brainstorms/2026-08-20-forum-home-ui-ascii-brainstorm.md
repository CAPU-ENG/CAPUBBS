# CAPUBBS 论坛 UI ASCII 设计

> 本文档是论坛全新 UI 的视觉与交互基线。当前覆盖首页与帖子详情；其他页面后续追加。

## 1. 设计目标

以阅读体验为核心，采用“知乎式阅读双栏 + 分端导航”：

- 首页只展示按最后回复时间排序的帖子，不设置内容切换 Tab 或频道栏。
- 桌面端使用稳定的主内容栏与辅助右栏，不设置常驻左侧栏。
- 桌面 Navbar 直接提供“首页 / 版块”；悬停“版块”出现抽屉与页面遮罩。
- 移动端保留三横线，打开抽屉形态的左侧栏，并保留独立活动栏。
- 帖子概况严格按照“标题 → 摘要 → 作者信息 → 评论 / 浏览”的顺序组织。
- 右栏只承载全局置顶与独立活动日历，不放发帖卡片或底部信息。
- 桌面端和移动端 Navbar 都提供昼夜模式切换。

## 2. 已确认决策

| 项目 | 决策 |
| --- | --- |
| 当前范围 | 首页 + 帖子详情 |
| 桌面布局 | 阅读双栏 |
| 首页内容 | 只展示最近回复，无 Tab / 频道栏 |
| 帖子概况 | 标题 → 摘要 → 迷你头像 / 作者 / 时间 → 评论数 / 浏览数 |
| 桌面板块导航 | “首页”右侧放“版块”，hover 展开抽屉与遮罩 |
| 移动板块导航 | 保留三横线，打开左侧抽屉式侧栏 |
| 顶栏操作 | 搜索按钮 + 昼夜切换 + 消息通知 + 头像菜单 |
| 已移除内容 | 搜索框、发帖按钮、写帖子卡片、右栏底部信息 |
| 右栏内容 | 全局置顶卡片 + 独立活动日历卡片 |
| 移动补充内容 | Navbar 下方增加活动栏 |
| 设置入口 | 头像菜单内 |
| 数据展示 | 板块抽屉 / 移动左侧栏的补充层 |
| 形状语言 | 以锐角矩形为标准；图标按钮、头像与日期选中框使用 `0.5px` 圆角 |

### 4.1 Navbar

- 高度固定为 `64px`，滚动时保持可见；使用纯色或轻微半透明白底。
- 桌面端 Logo 后依次放置“首页”和“版块”，不使用三横线菜单。
- 悬停或键盘聚焦“版块”直接打开板块抽屉与页面遮罩。
- 搜索为独立图标按钮，点击后直接进入搜索页；Navbar 不常驻输入框或悬浮搜索面板。
- 不提供发帖按钮。
- 昼夜切换是独立按钮；图标表达当前可切换到的模式，并提供文字辅助标签。
- 消息通知是独立按钮；存在未读消息时显示小圆点，不常驻展示长数字。
- 设置放入头像菜单；未登录时头像入口替换为“登录 / 注册”。

头像菜单：

```text
                         │  消息通知        │
                         ├──────────────────┤
                         │  设置            │
                         │  退出登录        │
                         └──────────────────┘
```

### 4.2 最近回复

- “最近回复”是内容区标题，不是 Tab，也不可切换。
- 帖子按最后回复时间倒序排列；同一帖子有新回复时只更新位置，不重复出现。
- 标题区不附加推荐、最新、精华或关注等频道入口。

### 4.3 帖子概况

```text
┌──────────────────────────────────────────────────────────────┐
│  帖子标题                                                    │  ← 18px / 26px，最多 2 行
│  正文摘要正文摘要正文摘要正文摘要正文摘要正文摘要正文摘要     │  ← 15px / 25px，最多 3 行
│  正文摘要正文摘要正文摘要正文摘要……                           │
│                                                              │
│  (迷你头像) 作者 · 相对时间                💬 评论数  ◉ 浏览数 │  ← 13–14px，次级信息
└──────────────────────────────────────────────────────────────┘
```

- 信息顺序严格为：标题 → 摘要 → 迷你头像 / 作者 / 时间 → 评论数 / 浏览数。
- 单元内边距建议 `20–24px`；单元间使用细分隔线，不把每条帖子做成悬浮卡片。
- 摘要取纯文本并截断，不展示 Markdown 标记、连续空行或超长链接。
- 迷你头像建议 `22–24px`；作者与最近回复时间左对齐，评论数与浏览数右对齐。
- 整个帖子单元可点击；头像和作者名可保留独立的个人主页链接。
- 首页概况不显示板块、收藏、分享或更多操作，保持固定信息层级。

### 4.4 辅助右栏

- 右栏只保留“全局置顶”和“活动日历”两张独立卡片。
- 不放写帖子卡片，不放关于、规则、反馈、版权等底部信息。
- 全局置顶最多展示 3–4 条，更多内容通过“查看全部”进入对应页面。
- 活动日历上半区展示整月日期，下半区展示选中日期或近期活动。
- 有活动的日期显示低干扰圆点；选择日期后只更新卡片下半区，不跳转页面。
- 两张卡片可随页面滚动吸附在 Navbar 下方，但日历内部不独立滚动。

### 5.1 分层规则

1. 第一层固定展示优先级最高的前 9 个板块，使用 `3 × 3` 网格。
2. 第二层展示其余板块；内容较多时展示首批入口，并提供“更多”。
3. 最后一层展示补充内容，例如“数据展示”；它与板块之间必须有明确分隔。
4. “设置”不出现在抽屉中，只保留在头像菜单内。

### 5.2 打开与关闭

- 桌面端指针进入“版块”即打开，不要求点击。
- “版块”触发项与抽屉组成连续 hover 区域；指针进入抽屉时保持打开。
- 指针同时离开触发项和抽屉后延迟约 `120–180ms` 关闭，避免经过边界时闪退。
- 抽屉打开时立即显示遮罩；点击遮罩或按 `Esc` 关闭。
- 键盘用户通过聚焦或按 `Enter / Space` 打开，并将焦点移入抽屉。
- 关闭后恢复原页面滚动位置。

- 点击活动进入活动详情；点击栏尾箭头打开完整活动日历。
- 活动栏可随 Navbar 吸附，但用户向下连续滚动时允许收起以释放阅读空间。

- 打开后锁定页面滚动，关闭时恢复原滚动位置。
- 昼夜切换与设置不放进侧栏：昼夜切换保留在 Navbar，设置保留在头像菜单。

### 6.3 移动内容规则

- 不显示推荐、最新、精华等频道栏。
- 帖子摘要最多 2–3 行；迷你头像、作者、时间、评论数和浏览数保持在底部一行。
- 触控目标至少 `44 × 44px`；不要仅依赖 hover 表达状态。
- 不设置浮动发帖按钮或底部常驻导航。

## 7. 昼夜模式

- 桌面端和移动端都在 Navbar 操作区提供昼夜切换按钮。
- 用户手动选择优先于系统偏好，并在后续访问中保持。
- 首次访问且没有用户选择时跟随系统 `prefers-color-scheme`。
- 切换只改变主题色，不改变布局、内容顺序或组件尺寸。
- 图标按钮必须有 `aria-label`，例如“切换到夜间模式”。

## 8. 视觉基线

```text
日间页面背景   #F6F7F6  中性浅灰
日间内容表面   #FFFFFF  纯白
日间主文字     #18181B  近黑
日间次级文字   #6B7280  灰
日间分隔线     #E5E7EB  浅灰
品牌主色       #237A57  CAPUBBS 绿
品牌浅色       #EAF5EF  选中背景
提醒色         #C2413B  仅用于“新”、未读、错误和重要提醒
```

- 夜间主题的完整色值在视觉稿阶段补充，但必须满足正文与背景对比度要求。
- 正文优先使用系统中文无衬线字体；不以装饰字体承载长文本。
- 卡片圆角统一为 `2px`；图标按钮、头像框与日期选中框使用 `0.5px` 锐角矩形，避免圆形或胶囊形控件。
- 按钮的 hover、focus 与 active 反馈必须沿用控件本身的矩形边界，不得在交互状态切换为圆形或胶囊形。
- 页面背景不放大面积插画、纹理或高饱和渐变。
- 动效时长建议 `160–220ms`；尊重系统“减少动态效果”设置。

## 9. 响应式变化

| 视口 | 布局 |
| --- | --- |
| `≥ 1100px` | 760px 主栏 + 304px 右栏；“版块”hover 抽屉 |
| `768–1099px` | 居中单栏；切换为三横线与移动左侧栏；保留活动栏 |
| `< 768px` | 全宽单栏；三横线左侧栏；活动栏；无频道栏 |

## 10. 关键状态

```text
加载中：保留与帖子单元等高的骨架屏，避免页面跳动。
空状态：说明“暂无最近回复”，不提供不存在的频道切换。
加载失败：在原位置显示重试按钮，不清空已加载内容。
抽屉打开：显示页面遮罩，保留原滚动位置，关闭后恢复。
无活动：桌面日历显示“当天暂无活动”；移动活动栏显示“近期暂无活动”。
未登录：允许阅读；通知与头像入口引导登录。
```

## 14. 帖子详情设计

### 14.1 设计方向

帖子详情参考 [Linux.do 话题页](https://linux.do/t/topic/2314452) 的楼层阅读结构，并结合 CAPUBBS 已有的楼层、楼中楼和只看楼主能力：

- 主楼和所有回复使用相同的楼层骨架，不做两套视觉组件。
- 每层左侧仅保留小面积头像列，右侧依次显示作者名称、正文与操作。
- 桌面端头像在当前楼层范围内保持 sticky，长回复滚动时仍能识别作者。
- 用户详情由头像 hover / focus 触发，不再要求点击。
- 页面右侧设置楼层目录与纵向时间线，承担阅读进度和快速跳转。
- 帖子正文仍是页面第一视觉焦点，目录和用户卡都使用低干扰样式。

### 14.2 桌面端整体布局

建议基准：视口宽度 `≥ 1180px`；主楼层流约 `840px`，间距 `24px`，右侧时间线约 `184px`。

### 14.3 帖子标题区

- 面包屑只显示所属板块与当前标题；板块名称可点击返回板块页。
- 标题使用页面最高文字层级，建议 `26–30px / 1.35`，长标题最多自然换为两行。
- 标题下只保留回复数、浏览数、“只看楼主”和“回复”入口。
- 不在标题区重复作者信息；作者属于主楼的楼层头部。
- 锁定、置顶、精华等状态以紧凑标签放在标题附近，只有存在时才显示。

### 14.4 统一楼层结构

```text
┌────────────────────────────────────────────────────────────────┐
│ (头像) │ 作者名称 / 身份标识                   时间 / 楼层编号 │
│ 44px   │──────────────────────────────────────────────────────│
│ sticky │ 正文                                                  │
│        │ 正文                                                  │
│        │                                                        │
│        │ 楼中楼（存在时）                                      │
│        │                                  引用  回复  更多      │
└────────────────────────────────────────────────────────────────┘
 56px                         剩余宽度
```

- 主楼与回复使用完全相同的左右结构；`#1` 和“楼主”标签用于表达主楼身份。
- 左头像列建议宽 `56px`，头像建议 `40–44px`，不放发帖数、等级等常驻资料。
- 头像只在所属楼层边界内 sticky，不能跨到下一层或遮挡 Navbar。
- 右侧顶部第一行依次为作者名称、身份标签；时间与楼层编号靠右。
- 正文字号建议 `16px`、行高 `1.75`，正文最大行宽约 `46–52` 个中文字符。
- 楼层之间使用 `16px` 间距或细分隔线，不使用高饱和边框区分作者。
- 操作区默认只显示“引用 / 回复 / 更多”；管理操作收进“更多”。

### 14.5 头像 hover 用户卡

```text
                         ┌──────────────────────────────┐
 (头像) ─── hover ─────▶ │  (大头像)  蓝色车架          │
                         │            ★★★  正式会员     │
                         │                              │
                         │  主题 24   回复 128   签到 36 │
                         │  最近在线：今天              │
                         │                              │
                         │  [查看个人主页]              │
                         └──────────────────────────────┘
```

- 桌面端指针悬停头像约 `150ms` 后显示；键盘聚焦头像时同样显示。
- 用户卡出现在头像右侧，覆盖正文上方但不推动楼层重新排版。
- 指针从头像移动到用户卡时保持打开；离开两者后延迟约 `120ms` 关闭。
- 卡片只展示识别用户所需的摘要资料，不在其中塞入完整个人中心功能。
- 点击头像仍可直接进入个人主页，不再负责打开用户卡。
- 移动端没有 hover：轻触头像打开同一内容的浮层，再次轻触或点外部关闭。

### 14.6 楼中楼

- 楼中楼位于对应楼层正文下方、操作区上方，并与主回复保持视觉从属关系。
- 默认展示前 `2–3` 条；更多内容通过“展开全部 N 条评论”在原位展开。
- 每条楼中楼展示小头像、作者、内容、时间和“回复”，不显示独立楼层编号。
- 回复某条楼中楼时明确显示目标用户，例如“回复 @小白杨”。
- 楼中楼较多时内部不设置固定高度滚动区，避免产生双重滚动。

### 14.7 右侧目录与时间线

目录和时间线合并为一个 sticky 组件，楼层圆点既表达时间顺序，也可直接跳转。

```text

│ 阅读进度   6 / 19  │
│                    │
│ 08.20 10:12        │
│      ○ #1 楼主     │  点击跳到主楼
│      │             │
│      ○ #2          │
│      │             │
│      ● #6 当前     │  当前视口楼层
│      │             │
│      ○ #12         │
│      │             │
│      ○ #19         │
│ 08.20 18:40        │
│                    │
│ [回到顶部] [回复]  │
└────────────────────┘
```

- 时间线固定在 Navbar 下方可视范围内，滚动帖子时保持可用。
- 当前楼层使用实心品牌色圆点，其余楼层使用低对比空心圆点。
- 短帖显示所有楼层；长帖抽样显示节点，当前楼层前后保留相邻楼层。
- 悬停节点显示作者、楼层号和一行摘要；点击节点平滑跳转并更新 URL 锚点。
- 组件顶部显示“当前楼层 / 总楼层”，上下端显示首末回复时间。
- 时间线不替代分页：跨页楼层跳转时加载目标页并定位到对应楼层。

### 14.8 回复入口

- 标题区和时间线底部都提供“回复”入口，打开同一个回复编辑器。
- 点击具体楼层的“回复”时，编辑器显示目标作者和楼层号。
- 编辑器默认以页面底部面板或居中弹层打开，不长期挤压正文宽度。
- 未登录、帖子锁定或权限不足时，在原入口附近解释原因，不展示可提交的假编辑器。

### 14.10 详情页状态

```text

楼层被删除：保留楼层编号与“该回复已删除”，保证引用和时间线连续。
只看楼主：时间线只显示楼主楼层，并明确标注筛选已开启。
定位失败：保留当前阅读位置，提示目标楼层不可用或已删除。
长正文：头像 sticky 只在当前楼层内生效，离开楼层边界即停止。
```
