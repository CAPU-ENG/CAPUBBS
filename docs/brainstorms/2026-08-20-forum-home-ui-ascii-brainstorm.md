# CAPUBBS 论坛首页 UI ASCII 设计

> 本文档是论坛全新 UI 的视觉与交互基线。首版只覆盖首页；帖子详情及其他页面后续在确认首页方向后追加。

## 1. 设计目标

以阅读体验为核心，采用“知乎式阅读双栏 + 论坛板块抽屉”：

- 用户进入首页后，第一视觉焦点始终是帖子内容，而不是导航或装饰。
- 桌面端使用稳定的主内容栏与辅助右栏；取消常驻左侧板块栏。
- 所有板块入口集中到抽屉，桌面端和移动端使用同一套信息架构。
- 首页帖子采用摘要流，让用户在进入详情前判断内容是否值得阅读。
- 借鉴知乎的信息层级和阅读节奏，不复制其配色、品牌或具体组件外观。

## 2. 已确认决策

| 项目 | 决策 |
| --- | --- |
| 首版范围 | 仅首页 |
| 桌面布局 | 阅读双栏 |
| 板块导航 | 抽屉收纳，不设常驻左栏 |
| 信息流 | 标题 + 2–3 行摘要的内容流 |
| 品牌识别 | 延续 CAPUBBS 绿色系，视觉更克制 |
| 后续范围 | 帖子详情确认后再设计 |

### 4.1 顶栏

- 高度固定为 `64px`，滚动时保持可见；使用纯色或轻微半透明白底，不使用大面积渐变和玻璃装饰。
- Logo 与“首页”提供当前位置识别；不在顶栏平铺所有板块。
- 搜索框是顶栏占宽最大的控件，默认搜索帖子，也允许在结果页切换板块或用户。
- “发帖”是唯一高强调按钮；消息与头像使用低强调图标。
- 未登录时，将消息与头像替换为“登录”和“注册”，不改变搜索框主位置。

### 4.2 内容频道

- 首版频道为“推荐 / 最新 / 精华”，一次只突出一个选中项。
- 频道栏在页面滚过顶栏后吸附于顶栏下方，避免用户回到顶部才能切换。
- 不新增“关注”等需要额外数据能力的频道；确认后再扩展。

### 4.3 帖子摘要单元

```text
┌──────────────────────────────────────────────────────────────┐
│  [板块]  ·  作者  ·  相对时间                                │  ← 12–13px，弱化
│  帖子标题                                                    │  ← 18px / 26px，最多 2 行
│  正文摘要正文摘要正文摘要正文摘要正文摘要正文摘要正文摘要     │  ← 15px / 25px，最多 3 行
│  正文摘要正文摘要正文摘要正文摘要……                           │
│                                                              │
│  💬 回复数     ◉ 浏览数     ☆ 收藏     ···                    │  ← 13–14px，次级操作
└──────────────────────────────────────────────────────────────┘
```

- 内边距建议 `20–24px`；单元之间使用细分隔线，而不是每条都做悬浮卡片。
- 标题必须比板块、作者和统计信息更醒目；摘要正文使用舒适行高。
- 摘要默认取纯文本并截断，不展示 Markdown 标记、连续空行或超长链接。
- 有高质量首图时，可在右侧出现 `160 × 100px` 缩略图；无图时文字自然占满宽度，不保留空槽。
- 整个标题和摘要区域可点击；操作区保留各自独立点击目标。
- “收藏”仅作为能力占位；若当前业务不支持，首版实现时移除，不以假按钮替代。

### 4.4 辅助右栏

- 右栏用于社区上下文，不与主内容争夺注意力；滚动时可在顶栏下吸附。
- 信息优先级暂定为：快速发帖 → 全局置顶 → 近期活动 → 页脚。
- 每个区块最多展示 3–4 条内容，更多内容通过“查看全部”进入对应页面。
- 不在右栏放大图轮播、自动播放内容或整月日历，避免打断阅读。

### 抽屉交互

- 点击顶栏菜单按钮打开；点击关闭按钮、遮罩或按 `Esc` 关闭。
- 打开后焦点进入抽屉，键盘焦点不应逃到遮罩后的页面。
- 右侧数字代表未读或近期新增数量；若无可靠数据则不显示。
- “常用板块”的收藏机制尚未确认；首版可根据最近访问生成，无法支持时隐藏整个分组。
- 抽屉内部内容超出视口时独立滚动，底部工具入口保持可访问。

### 移动端规则

- 顶栏只保留菜单、Logo、搜索和用户入口；发帖改为右下角悬浮按钮。
- 抽屉宽度为视口的 `86%`，最大 `320px`，结构与桌面一致。
- 摘要最多 2–3 行，统计操作使用图标加数字，避免一行塞入长文案。
- 帖子单元横向内边距建议 `16px`；正文最小字号 `15px`。
- 触控目标至少 `44 × 44px`；不要仅依赖 hover 表达状态。
- 不设置底部常驻导航，避免与浏览器工具栏及发帖按钮争夺空间。

## 7. 视觉基线

```text
页面背景       #F6F7F6  中性浅灰
内容表面       #FFFFFF  纯白
主文字         #18181B  近黑
次级文字       #6B7280  灰
分隔线         #E5E7EB  浅灰
品牌主色       #237A57  CAPUBBS 绿
品牌浅色       #EAF5EF  选中背景
提醒色         #C2413B  仅用于“新”、错误和重要提醒
```

- 正文优先使用系统中文无衬线字体；不以装饰字体承载长文本。
- 卡片圆角建议 `6–8px`，阴影极轻或不用；依赖边框和留白区分层级。
- 页面背景不放大面积插画、纹理或高饱和渐变。
- 内容区每行中文建议控制在约 `28–36` 字，详情页另行定义。
- 动效时长建议 `160–220ms`；尊重系统“减少动态效果”设置。

## 8. 响应式变化

| 视口 | 布局 |
| --- | --- |
| `≥ 1100px` | 760px 主栏 + 304px 右栏 |
| `768–1099px` | 居中单栏，最大 760px；隐藏右栏，保留顶栏发帖按钮 |
| `< 768px` | 全宽单栏；紧凑顶栏；悬浮发帖按钮；移动抽屉 |

中等宽度隐藏右栏时，不把所有右栏内容塞到信息流顶部；只保留一条最高优先级公告，其他内容从独立入口访问。

## 9. 关键状态

```text
加载中：保留与帖子单元等高的骨架屏，避免页面跳动。
空状态：说明当前频道暂无帖子，并提供“浏览其他频道”或“发布第一篇帖子”。
加载失败：在原位置显示重试按钮，不清空已加载内容。
抽屉打开：锁定页面滚动，保留原滚动位置，关闭后恢复。
未登录：允许阅读；收藏、发帖或消息操作触发登录提示。
```

## 10. 本轮不设计

- 帖子详情与楼层回复
- 搜索结果页
- 发帖编辑器
- 用户主页、消息与通知页
- 板块详情页
- 暗色主题的完整色值

这些页面应复用本首页确定的顶栏、内容宽度、抽屉和视觉基线，不在实现阶段临时另起一套样式。

## 11. 待确认问题

1. 右栏是否保留“近期活动”，以及活动入口的实际业务优先级。
2. “推荐”频道是否有可用排序逻辑；没有时是否改名为“热门”。
3. 首页是否支持收藏，以及未登录收藏的处理方式。
4. 帖子首图缩略图是否进入首版。
5. 板块的常用 / 收藏 / 未读数量是否有对应数据支持。
