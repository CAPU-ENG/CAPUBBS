# CAPUBBS 个人中心 UI 设计

> 本文档定义个人中心的页面定位、信息架构与桌面/移动端交互基线。个人中心是登录用户管理自身论坛内容的私有工作台，不替代公开个人主页。

## 1. 设计目标

个人中心采用“三层个人资料 + 内容工作区”，优先帮助用户完整查看自身论坛档案，并快速找到、回看和管理自己在论坛内留下的内容。

- 首版完整覆盖发帖、回复、报名、收藏、草稿箱和签名档六类内容。
- 参考 `BBS new`，首屏按身份摘要、可编辑资料、只读论坛档案三层呈现完整个人资料，但不把页面做成数据仪表盘。
- 个人简介和普通资料可在当前页面直接编辑；头像、邮箱、密码等敏感操作使用独立对话框。
- 消息继续由全局 Navbar 的通知入口承载，不加入内容 Tab，避免两个消息中心。
- 公开个人主页与个人中心保持明确边界：前者面向他人，后者面向本人管理。
- 延续论坛现有的自然绿、纸面阅读感和锐角矩形语言，形成“个人骑行档案台”的视觉印象。

## 2. 已确认决策

| 项目 | 决策 |
| --- | --- |
| 页面定位 | 内容工作台 |
| 页面骨架 | 三层个人资料 + 内容工作区 |
| 首版内容 | 发帖、回复、报名、收藏、草稿箱、签名档 |
| 资料层级 | 身份摘要 + 可编辑资料 + 只读论坛档案 |
| 资料编辑 | 简介与基础资料当前页编辑；头像、邮箱、密码使用独立对话框 |
| 消息入口 | 保留在全局 Navbar，不加入个人中心 Tab |
| 公开主页 | 独立页面；个人中心提供“查看公开主页”入口 |
| 默认内容 | 发帖 |
| 桌面内容布局 | 主列表 + 右侧筛选辅助栏 |
| 移动内容布局 | 单栏；Tab 横向滚动，筛选折叠展开 |
| 形状语言 | 与论坛统一，以锐角矩形和 `0.5px` 小圆角为主 |

### 4.1 身份摘要

- 身份摘要不是大幅封面，不使用与论坛无关的装饰背景；用极淡的自行车线路纹理或分区细线建立识别度。
- 头像建议 `72px` 方形、小圆角；点击打开头像预览与更换对话框。
- 用户名是首要标题，星级紧随其后；个人简介最多显示两行。
- “编辑资料”是主要操作，“账号安全”是次要操作；不在身份摘要中重复放消息按钮。
- 身份摘要只承担身份识别与主要操作，不再把基础资料和论坛数据压进同一行。
- 编辑状态下，个人简介在原位置替换为输入控件；切换 Tab 不应自动丢弃未保存修改。

### 4.2 可编辑资料

- 参考 `BBS new`，完整保留爱好、QQ、Email、地点四项，并使用四张等宽资料卡与身份摘要分层。
- 爱好、QQ、地点在“编辑资料”状态下原位变为输入控件；Email 始终通过“管理”进入独立邮箱对话框。
- 空值显示“未填写”，不以“未知”或占位符冒充真实资料。
- Email 在个人中心可显示完整地址；其验证状态与公开状态必须同时可见。公开主页仍按公开状态决定是否展示。
- 保存与取消操作统一放在身份摘要的操作区，不在四张资料卡中重复放按钮。

### 4.3 只读论坛档案

- 参考 `BBS new`，完整展示发帖数、签到数、上次在线、权限值、回复数、灌水数、注册时间、精品数八项。
- 这些字段均由论坛数据生成，不进入资料编辑状态；无值时显示 `--`。
- “上次在线”和“注册时间”使用紧凑日期格式，但必须保留可理解的年份或完整时间提示。
- 权限值是系统身份信息，不转换成含义不明的等级名称；如后续建立统一权限文案，再同时显示名称。
- 档案数据只用于概览，不允许点击后产生与下方内容 Tab 重复的导航行为。
- 桌面端为八列单行；窄桌面可换为四列两行，移动端固定为两列四行。

### 4.4 内容 Tab

- 顺序固定为：发帖、回复、报名、收藏、草稿箱、签名档。
- 默认打开“发帖”；刷新后由 URL 查询参数恢复当前 Tab，例如 `/user-center?tab=bookmarks`。
- Tab 使用同一条分段导航，不拆成两行；数字只显示当前总量，不显示筛选后的数量。
- 活动项使用“报名”而不是“活动”，强调用户已经执行的动作。
- 草稿箱存在内容时显示数量，但不使用红点；红色只留给错误和危险操作。

### 4.5 记录列表

- 同一 Tab 内的记录共享一个连续表面，以细分隔线区分，避免每条记录悬浮成卡片。
- 标题、摘要和元信息层级延续首页帖子概况，降低学习成本。
- 记录整行可打开目标内容；版块名、作者名等仍保留独立链接。
- 每页默认 `20` 条；筛选或切换 Tab 后回到第一页。
- 危险操作不常驻：草稿行在 hover/focus 或“更多”菜单中提供删除，删除前二次确认。

六类记录的差异：

| Tab | 主信息 | 次信息 | 行尾信息 / 操作 |
| --- | --- | --- | --- |
| 发帖 | 帖子标题 + 摘要 | 版块、发布时间 | 回复、浏览、收藏 |
| 回复 | 所回复的帖子标题 + 回复摘要 | 版块、回复时间 | 直达对应楼层 |
| 报名 | 活动名称 | 报名时间、活动时间 | 已报名 / 候补 / 已取消 |
| 收藏 | 帖子标题 + 摘要 | 作者、版块、收藏时间 | 回复、浏览、取消收藏 |
| 草稿箱 | 草稿标题 + 内容片段 | 发帖草稿 / 回帖草稿、更新时间 | 继续编辑、删除 |
| 签名档 | 签名档 1–3 的渲染预览 | 内容模式、关联来源 | 编辑、清空 |

### 4.6 筛选辅助栏

- 发帖、回复、报名、收藏和草稿箱提供关键词与日期范围筛选。
- 签名档最多三个固定槽位，不显示筛选栏；右栏只保留公开主页入口。
- 关键词搜索范围包括标题、版块、摘要和状态，不触发全站搜索。
- 日期为空代表不限；开始日期晚于结束日期时在字段下方就地提示。
- 辅助栏不设置独立滚动，也不强制 sticky；与主内容共用页面滚动。

### 5.1 移动端规则

- 身份摘要头像缩小到 `56px`，身份信息与头像同排，操作按钮下一行等宽排列。
- 可编辑资料使用两列网格；字段内容自然增高，不截断爱好和 Email 状态。
- 只读论坛档案使用两列四行，完整保留八项数据，不做横向滚动或字段折叠。
- 六个 Tab 保持单行横向滚动；切换后自动将当前项滚入可视区域。
- 内容标题区右侧显示“筛选”按钮；点击后在 Tab 下方展开筛选面板，不使用全屏抽屉。
- 展开筛选时保留当前列表，不遮挡 Navbar；应用筛选后自动收起并回到列表顶部。
- 记录元信息允许换成两行，但标题和摘要不超过两行。
- “查看公开个人主页”放在列表末尾，避免占用首屏内容空间。

## 6. 对话框

### 6.1 头像

- 点击头像先进入预览，再选择“更换头像”。
- 支持上传图片和填写允许的图片地址；上传前展示裁切后的方形预览。
- 保存期间禁用重复提交，失败时保留用户已选择的图片。

### 6.2 邮箱管理

- 展示脱敏邮箱、验证状态和公开状态。
- 修改邮箱、发送验证码、验证邮箱在同一对话框内按步骤进行。
- “公开邮箱”必须是显式开关，默认不因修改邮箱而自动开启。

### 6.3 账号安全

- 首版只包含修改密码，不混入界面偏好或消息设置。
- 修改密码需要当前密码、新密码、确认新密码。
- 成功后明确提示是否需要重新登录；失败原因显示在对应字段附近。

## 7. 状态设计

| 状态 | 表现 |
| --- | --- |
| 未登录 | 显示简洁登录提示与“登录”主按钮，不渲染个人数据骨架 |
| 首次加载 | 三层个人资料、Tab 和首批记录使用与真实布局等高的骨架 |
| Tab 加载 | 保留个人资料区和 Tab，只替换记录区骨架 |
| 空内容 | 针对不同 Tab 给出下一步，如“去发帖”或“浏览论坛” |
| 筛选无结果 | 保留筛选条件，提示“没有符合条件的记录”并提供重置 |
| 保存成功 | 个人资料区下方显示低干扰成功提示，数秒后消失 |
| 保存失败 | 保留编辑内容，显示可恢复的错误提示 |
| 会话失效 | 提示重新登录，并保留本地草稿类内容 |

## 8. 视觉与动效

- 主色继续使用论坛现有 `--brand` 自然绿，强调色只用于当前 Tab、主操作和验证状态。
- 个人资料区以纸张式浅表面和细线分区体现“档案台”，避免渐变英雄横幅与大面积装饰色。
- 中文标题沿用现有宋体标题体系；正文和控件沿用现有中文无衬线字体栈。
- 页面入场只对个人资料区、Tab、内容区做一次轻微错峰上移淡入，时长控制在 `180–260ms`。
- Tab 切换使用短距离内容淡入，不让整个页面重新闪烁。
- 所有动效尊重 `prefers-reduced-motion`。
- 深色模式使用现有 token，不另建一套颜色系统。

## 9. 路由与页面边界

- 个人中心目标路由：`/user-center`。
- 公开个人主页继续使用 `/users/:name`。
- 当前 Tab 写入查询参数：`/user-center?tab=replies`。
- 筛选条件是否写入 URL 留到实现计划决定；首版可只保留在当前会话状态。
- 旧 `/bbs/home/` 的兼容方式属于实现与部署规划，不在本设计文档中决定。

## 10. 暂不纳入首版

- 关注者 / 正在关注。
- 勋章墙、等级进度或游戏化任务。
- 个人动态时间线。
- 多设备登录管理。
- 通知偏好和界面偏好。
- 批量删除、批量移动或批量取消收藏。
